Tarutaru horns - example FFXI model mod
=======================================

A Tarutaru face model (ROM/46/100.DAT) with horns added in Blender using
the ffxi_dat_blender add-on. The horns are skinned to the head and the
game mirrors them, so one horn in the file shows up on both sides.
Shown in in_game.webp (this folder).

This only changes what YOUR game client displays. Other players see
the normal model.

INSTALL
-------
1. Open your FFXI install folder (the one that contains the ROM folder),
   e.g. ...\SquareEnix\FINAL FANTASY XI\
2. Back up ROM\46\100.DAT (copy it somewhere safe).
3. Copy ROM\46\100.DAT from this folder over the game's ROM\46\100.DAT.
4. Start the game and use the matching Tarutaru face.

UNINSTALL
---------
Copy your backup back to ROM\46\100.DAT.

NOTES
-----
- If a launcher update or file check restores the original file, copy
  this one in again.
- To make your own version, import the original 100.DAT (with the
  Tarutaru skeleton 93.DAT) in Blender - see ../README.md.
